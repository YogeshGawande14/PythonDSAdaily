# 🐍 Python Data Structures & Algorithms (DSA)

A structured repository containing daily problem solutions, core patterns, and implementation templates for technical interview preparation.

---

## 📌 Core Topics & Important Algorithms

This repository organizes solutions by fundamental data structures and the essential algorithms required to master them:

### 1. Arrays, Strings & Hashing
* **Core Concepts:** Subarrays, Substrings, Frequency Counting.
* **Important Algorithms:**
  * **Two Pointers:** Opposite ends, fast & slow pointers.
  * **Sliding Window:** Fixed and variable-size window patterns.
  * **Prefix Sum & Hash Maps:** $O(1)$ lookups and cumulative range queries.

### 2. Searching & Sorting
* **Important Algorithms:**
  * **Binary Search:** Standard search, lower/upper bound, search on answer space.
  * **Sorting:** Merge Sort, Quick Sort, Quickselect (Kth largest/smallest).

### 3. Linked Lists, Stacks & Queues
* **Important Algorithms:**
  * **Reversal Patterns:** In-place linked list reversal, sublist reversals.
  * **Monotonic Stack:** Next greater element, histogram problems.
  * **Fast & Slow Pointers:** Cycle detection (Floyd's algorithm), finding the middle node.

### 4. Trees & Graphs (Hierarchical Structures)
* **Important Algorithms:**
  * **Tree Traversals:** Preorder, Inorder, Postorder, Level Order (BFS).
  * **Graph Traversals:** Depth-First Search (DFS), Breadth-First Search (BFS).
  * **Advanced Graph Algorithms:** Dijkstra's (Shortest Path), Topological Sort (Kahn's Algorithm), Union-Find (Disjoint Set).

### 5. Dynamic Programming (DP) & Recursion
* **Important Algorithms:**
  * **Memoization & Tabulation:** Top-down vs. bottom-up optimization.
  * **Classic Problems:** 0/1 Knapsack, Longest Common Subsequence (LCS), Longest Increasing Subsequence (LIS), Coin Change.
